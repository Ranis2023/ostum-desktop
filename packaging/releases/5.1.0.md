# OSTUM Desktop 5.1.0

В рабочих пространствах появился стартовый экран с перетаскиванием файлов, подсказками и учебным документом. На узком экране список папок и файлов открывается отдельной кнопкой. При выборе абзаца OSTUM подсвечивает текст. На вкладке **Правки** видно, что будет записано при сохранении.

С этой версии рабочие пространства Pro доступны после проверки подписки на канал Раниса Галиаскарова. Откройте **Рабочие пространства Pro**, подпишитесь на канал, нажмите **Проверить подписку в Telegram** и запустите бота. Сохраните полученный `.ostumpro` и перетащите в OSTUM. Подтверждение действует семь дней и позволяет работать офлайн. Для изолированного ПК файл можно получить через другое устройство. При продлении бот снова проверит статус в канале. [Канал Раниса Галиаскарова](https://t.me/ranisgaliaskarov) · [Бот OSTUM](https://t.me/rangoostum_bot)

Базовый чат Zarum, голос, анализ изображений и рисование доступны без подписки. Для установки запустите **Ostum-Desktop-Setup.exe**. При первом полном развёртывании он загрузит 13,38 ГБ моделей. Установщик выпускается без подписи издателя. Контрольная сумма приложена в `SHA256SUMS.txt`.
