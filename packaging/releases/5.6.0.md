# OSTUM Desktop 5.6.0

[English release notes](HISTORY.en.md#560)

В чате, просмотре файлов, рабочих пространствах и настройках появились 55 векторных значков OSTUM. Во время диктовки значок микрофона меняется на звуковые полосы. Нажмите на них, чтобы завершить запись. Пока идёт распознавание, его можно отменить. Название действия доступно при наведении и программе экранного доступа.

Боковая панель загружает список диалогов по локальному указателю. В нём хранятся заголовки, даты и состояние архива. Текст сообщений загружается при открытии диалога. При первом запуске обновление строит указатель из существующей истории. Если указатель повреждён, приложение восстанавливает его из файлов диалогов.

При повторной работе с Word и Excel OSTUM использует уже запущенный локальный процесс чтения. Для каждого запроса приложение проверяет права на папку, а редактор заново открывает файл. Через 45 секунд простоя процесс завершается. При переходе к другому рабочему пространству OSTUM запускает для него отдельный процесс чтения.

Когда вы прокручиваете длинный ответ вверх, новые фрагменты оставляют открытым выбранное место. Кнопка «К последнему сообщению» возвращает к ответу. Лента этапов обновляет только те значки, состояние которых изменилось.

Калькулятор умеет выделять явно включённый процентный сбор из итоговой суммы. Например, при общей цене 12 480 рублей и включённом сборе 20% размер самого сбора составляет 2 080 рублей.
