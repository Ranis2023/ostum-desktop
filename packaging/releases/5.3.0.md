# OSTUM Desktop 5.3.0

## Уведомления и обновление из программы

При запуске и раз в шесть часов OSTUM проверяет стабильный выпуск на GitHub. Когда доступна новая версия, её номер появляется в шапке чата. Для свёрнутого окна OSTUM отправляет уведомление Windows один раз на выпуск. Установщик скачивается в фоне. Перед запуском OSTUM проверяет размер, SHA-256 из метаданных выпуска и версию EXE. Нажмите «Установить и перезапустить», закончив работу с черновиком. Обновление заменяет приложение и его движки, сохраняя диалоги, доступ Pro и библиотеку моделей.

Обе настройки находятся под логотипом OSTUM. Политика организации блокирует внешние проверки. Для перехода с 5.2 и более ранних версий один раз запустите новый [установщик для Windows](https://github.com/Ranis2023/ostum-desktop/releases/latest/download/Ostum-Desktop-Setup.exe).

## Документы и ответы

Поиск в прикреплённых документах учитывает редкие термины, формы русских слов и полные артикулы. Фрагмент для Zarum включает место совпадения даже в длинном абзаце. До четырёх последних документов индексируются в оперативной памяти для повторных вопросов. Явно запрошенные поля карточки, в том числе даты и дробные числа, переносятся вместе с единицами измерения. При противоречивых полях задачу получает модель.

На одном ПК с Ryzen 7 7435HS и RTX 4050 Laptop проверили два сценария на одинаковых данных.

| Проверка | 5.2.0 | 5.3.0 |
| --- | ---: | ---: |
| В выдержку для модели попало нужное значение, 8 запросов к 240 каталожным листам | 0 из 8 | 8 из 8 |
| Повторный поиск по проиндексированному каталогу, медиана | 17,58 мс | 0,10 мс |
| Чат вернул полное запрошенное поле карточки с сохранением даты, кода или единицы | 0 из 4 | 4 из 4 |
| Время ответа для этих четырёх полей, медиана | 1,30 с | 0,02 с |

Первый поиск с построением индекса занял 56 мс, в предыдущей версии первый поиск занимал 34 мс. Замеры относятся к указанным заданиям. Базовые веса Zarum 9B те же. ## Загрузка при установке

Автономный EXE использует современную защиту HTTPS Windows. При временной ошибке доступа к файлу модели загрузчик запрашивает свежую ссылку и продолжает с сохранённой позиции. Сообщение об ошибке показывает имя файла и путь к журналу.

Для новой полной установки на Windows 10/11 x64 нужны интернет при загрузке 13,38 ГБ весов и от 20 ГБ свободного места. Для установки без интернета используйте заранее подготовленный комплект. Выпуск распространяется без подписи издателя. Контрольная сумма приложена к выпуску. [Руководство](https://github.com/Ranis2023/ostum-desktop) · [Канал разработчика](https://t.me/ranisgaliaskarov)
