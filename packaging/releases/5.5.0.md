# OSTUM Desktop 5.5.0

[English release notes](HISTORY.en.md#550)

В открытой книге команда «Посчитай сумму B2:B31» проверяет весь диапазон и показывает, сколько ячеек содержат числа. Работают также среднее, минимум и максимум. Пустая ячейка, текст и настоящий ноль учитываются по правилам агрегатных функций Excel. Правка «Измени B2 на 9750 и C2 на 30» создаёт две строки для проверки. В книгу попадают только подтверждённые изменения.

Прикрепите скан PDF и выберите строку в предпросмотре, чтобы увидеть место на странице. Распознавание выполняет Windows на компьютере пользователя. Для партии входящих документов в Pro подключите папку с разрешением на локальный анализ и напишите «Собери реестр счетов». Перед сохранением можно сверить поля с оригиналом, исправить данные и снять выбор с повторов.

Команды «Что просрочено?» и «Что сдаём на неделе?» читают открытые поручения из реестра папки. Команда «Сохрани сроки в календарь» создаёт файл ICS для импорта в календарное приложение.

Оркестратор учитывает просьбу вернуть только текст. В ответах на запросы полей по двум вложениям доступны дословные выдержки с названием документа и местом в нём. Диалог по открытому файлу помнит недавние реплики разрешённого сеанса. В обычном чате можно удалить одну личную заметку по её отличительным словам.

В настройках изображений доступны размеры 384, 512 и 1024. Для замены ровного однотонного фона используется локальная обработка изображения. При переходе сложной генерации на процессор можно выбрать продолжение, уменьшенный эскиз или отмену.

Локальная студия адаптеров использует установленное ускорение CUDA, показывает оценку базовой и обученной модели и предупреждает о малом числе контрольных примеров. Прослушивание микрофона, генерация музыки и проверка обновлений доступны через привычные элементы управления.
