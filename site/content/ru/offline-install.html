Что загрузить заранее

На GitHub скачайте Ostum-Desktop-Setup.exe. В версии 5.7.0 файл весит 108,3 МиБ. Он содержит программу и среды выполнения. При первой полной установке на новом компьютере он отдельно загрузит шесть файлов моделей на 13,38 ГБ. Для локального чата нужен комплект Zarum 9B, в том числе зрительный проектор для фотографий.

На компьютере с интернетом можно сразу запустить EXE. Предусмотрите от 20 ГБ свободного места на SSD. Установщик выпускается без подписи издателя. Сумму из команды Get-FileHash .\Ostum-Desktop-Setup.exe -Algorithm SHA256 можно сверить с файлом SHA256SUMS.txt из того же выпуска.

Если целевой компьютер отключён от сети

  1. На подключённом ПК подготовьте библиотеку моделей. Если понадобится музыка, сначала загрузите дополнительный модуль ACE-Step. Для целевой NVIDIA подготовьте также ускоритель CUDA.
  2. Откройте команды сборки автономной папки. Они копируют и проверяют файлы из подготовленной библиотеки. Полный комплект 5.7.0 с музыкой и CUDA занимает около 17,6 ГБ.
  3. Перенесите всю папку на флешку с NTFS или exFAT. Рядом с EXE должны остаться Models, Acceleration и OSTUM-OFFLINE.txt. Запустите установщик из этой папки на целевом ПК.

Как проверить результат

Перед установкой проверьте файлы на самой флешке. Для версии 5.7.0 скрипт PowerShell сверяет 15 файлов полного комплекта с эталонными SHA-256 выпуска или три файла для чата и фотографий. На подготовленном комплекте совпали все 15 файлов. Отдельную копию установщика с изменённым байтом скрипт распознал даже при прежнем размере файла. Инструкция и скрипт проверки флешки

На отключённом от интернета ПК откройте новый чат. Спросите «Составь список из трёх вещей для поездки». Затем приложите учебную фотографию и попросите описать один видимый предмет. Так вы отдельно проверите текстовую модель и зрительный проектор. Протоколы встреч используют модуль диктовки, а генерация изображений — файлы модуля рисования.

Бесплатному чату аккаунт не нужен. Для Pro QR-код из приложения можно открыть на подключённом телефоне. После проверки подписки перенесите подписанный файл подтверждения в OSTUM. Для рабочих станций с правилами организации есть отдельная инструкция. Корпоративная установка
