Локальный ИИ для Windows

Обсудите документ, расшифруйте встречу или сверьте два прайса. Модель Zarum 9B работает на вашем компьютере.

Скачать для Windows ↓Установить с флешки
Windows 10 и 11 x64 · Установщик 5.7.0 весит 108,3 МиБ

После загрузки — офлайн

Полная установка на новом ПК скачивает 13,38 ГБ моделей. Для Zarum 9B ориентируйтесь на 16 ГБ ОЗУ и 20 ГБ свободного места на SSD.

Сначала попробуйте чат

Обычному чату не нужен аккаунт. Можно приложить фото или PDF, задать вопрос голосом и проверить ответ по фрагменту документа.

Как открыть Pro

Редакторы Word и Excel открываются после первой проверки подписки на канал разработчика. Доступ бессрочный для этой установки и пользователя Windows.
