Install OSTUM on a PC without internet access

Prepare the model files on a connected PC, copy the kit to removable media and verify your first offline conversation.

What the download contains

The Windows installer for 5.7.0 is 108.3 MiB. It includes the app and local runtimes. A full first installation on a new PC downloads another 13.38 GB in six model files. These cover Zarum 9B and its vision projector, Whisper dictation and Z-Image drawing. Allow at least 20 GB of free SSD space.

Run the installer directly on a connected PC. This release is unsigned. To check the file, run Get-FileHash .\Ostum-Desktop-Setup.exe -Algorithm SHA256 in its download folder and compare the result with the checksum supplied with that release.

Prepare removable media for an isolated PC

  1. On a connected workstation, prepare the model library. If the target needs music, download the optional ACE-Step module first. Include the CUDA libraries if the target should use NVIDIA acceleration.
  2. Use the two PowerShell commands in the USB preparation instructions with the matching release. They assemble and check the contents. A full 5.7.0 kit with music and CUDA occupies about 17.6 GB.
  3. Copy the whole folder to NTFS or exFAT media. Keep Models, Acceleration and OSTUM-OFFLINE.txt next to the EXE. On the disconnected PC, start the installer from that folder.

Verify a local session

With the target computer offline, open a new chat and request a three-item packing list. Next attach a sample photo and ask for one visible detail. The two requests exercise the language model and the vision projector separately. Meeting transcription also needs the dictation component.

Free chat works without an account. For the Pro workspace, scan the activation QR with a connected phone and bring the signed response back to the workstation. The first activation requires a verified subscription to the developer’s Telegram channel. Company deployment guide in Russian
